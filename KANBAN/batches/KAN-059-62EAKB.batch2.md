# KAN-059-62EAKB 배치2 — 남은 자리에 테두리를 달고 화면으로 확인한다

배치1 이 세운 빨강(게이트·실제 입력)을 초록으로 돌린다. 모든 자리가 배치1 의 `useFocusVisible()` 과 `FOCUS_RING` 하나를 쓴다.

## 1. 작업 패키지

### WP1 · `S4` 자기 자신에 그리는 자리

| 컴포넌트 | 고칠 것 |
|---|---|
| Button | `outline: 'none'`(`Button.tsx:153`) 자리에 키보드 포커스면 `FOCUS_RING`. 소비자 `style` 이 여전히 마지막에 이긴다 |
| Link | 모든 변형에 `FOCUS_RING`. 상자 변형의 box-shadow 고리(`Link.tsx:116, 160-169`)는 걷는다 |
| Dock 항목 | 포커스 때 확대는 그대로 두고 테두리를 더한다 |
| TreeView 항목 · Menu 항목 | 항목 안쪽 간격 변형 후보. S6 화면 확인에서 정한다 |
| ScrollArea | `tabIndex=0` 상자 자체 |

**완료 기준**: 해당 실제 입력 항목 초록(Tab → `solid 2px`, 클릭 → `none`), 해당 스토리 초록.

### WP2 · `S5` 감싼 상자와 숨긴 입력

| 컴포넌트 | 고칠 것 |
|---|---|
| Input(기본·composer) | 안쪽 input 에 포커스가 오면 감싼 상자에 `FOCUS_RING`. 기존 테두리 색 변화는 남긴다. 내부 `onFocus`·`onBlur` 가 `{...props}` 에 덮이던 것(`Input.tsx:264-275, 314-332`)을 합성으로 |
| Textarea | 자기 자신이 상자 |
| Searchfield | 바깥 상자 |
| NumberField | 입력은 바깥 상자, 증감 버튼 둘은 각자 자기 자신(한 파일이라 여기서 함께 고친다) |
| RichTextEditor | 바깥 상자(이미 있는 `isFocused` 와 나란히) |
| Switch | 숨긴 input 의 포커스로 트랙에 |
| Radio `segmented` | 숨긴 input 의 포커스로 그 조각에 |
| NumberField `seven-segment` | 숨긴 input 의 포커스로 판에 |

**완료 기준**: 실제 입력 항목 전부 초록, S1 게이트(`test:unit` 포커스 표시 검사) 초록.

### WP3 · `S6` 화면 확인과 마무리

- 빌드한 Storybook(`storybook-static`)을 띄우고 Playwright 로 실제 Tab 을 보내 S4·S5 의 자리마다 화면을 찍는다. 테두리가 상자 `overflow` 에 잘리거나 이웃 항목을 덮는지 본다. Menu·TreeView 항목은 여기서 바깥(`2px`)·안쪽(`-2px`) 간격을 정한다.
- 같은 화면에서 실제 클릭으로 눌러 테두리가 없는지(글자 입력칸 제외) 본다.
- `.changeset/kan-059-focus-ring.md` — core minor. 카드 「바뀌는 동작」 다섯 줄.
- 게이트 5종을 CLAUDE.md 순서대로. 검토서를 뜬다.

**완료 기준**: 게이트 5종이 초록이고 검토서 정본이 서서 검토로 옮길 수 있다.

## 2. 의존과 순서

S4·S5 는 서로 다른 파일만 고친다. NumberField 는 증감 버튼(자기 자신에 그림)과 입력(감싼 상자)이 한 파일이라 S5 에 몰았다. S6 은 S4·S5 가 끝나야 화면을 찍을 수 있다.

## 3. 리스크

| 리스크 | 징후 | 대응 |
|---|---|---|
| 테두리 2px + 간격 2px 이 좁은 자리에서 잘린다 | S6 화면에서 고리가 일부만 보임 | 그 자리만 안쪽 간격 변형으로. 규칙을 하나 더 만들지 않는다 |
| Input 합성 변경이 외부 앱의 `onFocus` 동작을 바꾼다 | 전에는 소비자 `onFocus` 만 돌았는데 이제 내부 처리도 돈다 | changeset 「바뀐 동작」에 적고 검토 판단 항목에 올린다 |
| 스타일 가이드가 Button·Input 을 감싸 테두리를 다시 끈다 | 카탈로그 스토리에서만 테두리가 없음 | S6 화면 확인에 카탈로그 스토리 두셋을 넣는다. 감싼 쪽이 끄면 범위 밖으로 기록한다 |
