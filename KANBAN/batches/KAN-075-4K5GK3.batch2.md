## 1. 작업 패키지

### WP1 · `S4` 문서와 changeset

| 파일 | 고치는 것 |
|---|---|
| 루트 `README.md` | 가이드 글자색 설명(KAN-069 가 `on` 을 적은 자리)에 `on.ink` 의 동작과 우선순위 |
| `packages/visualization/viz-style-expansion.md` | 가이드 저작 규칙: 지침 문장에 글자색을 이름으로 적으면 `on.ink` 와 카탈로그 `textInk.test.ts` 표에도 넣는다. 기계는 문장을 못 읽어서 표에 안 넣으면 못 잡는다 |
| `.changeset/kan-075-*.md` | tokens·visualization minor(선택 칸 추가), catalog minor(7개 가이드 12개 색 묶음의 글자색이 바뀜) |

### WP2 · `S5` 품질 게이트

5종을 CLAUDE.md 순서로 `bash -c` 에서 돈다 — `pnpm typecheck` · `pnpm build` · `pnpm test` · `pnpm --filter storybook build` · `pnpm test:unit`. 고친 스토리 파일만 `a11y: { test: 'error' }` 로 임시 강제해 돌린 뒤 되돌린다(`pnpm test` 는 a11y 위반을 실패로 안 잡는다).

**완료 기준**: 다섯 다 초록, a11y 결과를 수행 내역에 적는다.
