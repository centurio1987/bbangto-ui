## 1. 작업 패키지

### WP1 · `S6` README 조립

워커 4개의 산출물을 한 문서로 잇는다. 순서는 **처음 온 사람이 읽는 순서**다.

1. 히어로 + 한 줄 정의 (기존 유지)
2. **사례 라우팅 표** — "무엇을 만들려는가 → 어느 사례로" (새로 넣는 것 중 가장 중요한 한 덩이)
3. 사례 1~8 본문 (배치 2 산출물)
4. 패키지 표 — 사례 열을 더해 재작성. **수치를 실측으로 갱신**(24→51, 74→76, viz 30, 유형 87)
5. 개발·품질 게이트 (기존 유지, 사례 8과 중복 제거)
6. 함께 보기 — `DESIGN_SYSTEM_GUIDE.md` 등으로 넘기는 링크

기존 절 중 **Foundation System · Style Guide Catalog · Motion Layer · Visualization Package** 넷은 사례 본문과 겹친다. 지우지 않고 **사례로 흡수하거나 참조로 축약**한다 — 모션 atom 26종 표처럼 사례에 안 들어가는 목록은 남긴다.

**완료 기준**: `README.md` 가 통째로 교체되고, ① 사례 8종이 전부 있고 ② 수치가 S1 실측과 한 자리도 다르지 않고 ③ 내부 링크가 실재하는 파일·앵커를 가리킨다.
