### 검토 결과 (2026-11-24, visualization 2.1.0)

원문의 도식 여섯 종류와 프레임워크 셋, 범례 규칙을 viz 템플릿과 하나씩 맞춰 봤다. 기준은 노드 종류·화살표 의미·시간 축을 템플릿 데이터만으로 그릴 수 있는가다.

범례 규칙(화살표 의미를 섞으면 범례로 구분한다)은 지금 viz 로 지킬 수 없다. 도식용 범례 부품이 없고(Statistics 와플 안의 범례뿐), C4·배포·아키텍처·네트워크 템플릿에는 선마다 모양을 바꿀 칸이 없다. 이것은 .2 가 맡는다.

### 근거

- 서버 렌더: scratchpad 스크립트를 `tsx --conditions=bbangto-source` 로 돌려 Flowchart · StateDiagram · ClassDiagram · C4ContainerDiagram · UMLDeploymentDiagram · ArchitectureDiagram 에 라벨을 넣었다. 노드 이름과 선(connector path 1개)은 나왔고 라벨 글자는 0건이었다. 비교용으로 넣은 DataFlowDiagram 은 흐름 라벨이 나왔다.
- 코드: BlockDiagram · C4ContextDiagram · C4ComponentDiagram · C4CodeDiagram · UMLComponentDiagram · ERDiagram 도 `<Edge>` 에 라벨을 넘기지 않고 EdgeLabel 을 두지 않는다. 확인 명령은 `grep -n "<Edge" packages/visualization/src/templates/*.tsx` 다.
- Edge 원자는 label 을 받고 버린다. 원문: `packages/visualization/src/atoms/Edge.tsx:71` 의 `label: _label`.
- ClassDiagram 의 `edgeConfig` 는 composition·aggregation 에 markerEnd 를 주지 않아 Edge 기본값 `arrow` 가 붙는다. ClassSpec.stereotype 은 ClassBox 에 넘기지 않는다.
- 데이터 형식: C4BoxProps·C4ContainerSpec 에 모양 칸이 없고, UMLDeploymentNodeSpec 에 종류·부모 칸이 없고, TopologyLink 에 label 이 없다.
- 유형 목록 `packages/visualization/visualization-type-inventory.md` 는 VT-101 별칭에 object diagram, VT-108 별칭에 communication 을 두고 둘 다 구현 완료로 적었다. 그 표기를 그리는 export 는 없다. 같은 문서 §8-b 는 LegendBlock 을 프리미티브 수준 빈칸으로 적어 두었다.
- 바깥 보고서 `~/resume/docs/viz-upstream-issues.md` 의 P7(선언 필드를 안 그림, Class·ER 만 적음) · P8(Edge.label 을 버림) · P9(ClassBox 빈 칸을 못 숨김) · P11(관계 매핑을 export 하지 않음, 포함·집합 화살촉)과 같은 결함이다. 이번 검토로 P7 의 범위가 템플릿 12개라는 것이 더해졌다.
