# @centurio1987/bbangto-ui-hooks

bbangto-ui가 쓰는 **headless React 훅** 모음. 렌더를 포함하지 않으므로 코어 컴포넌트 없이 단독으로 쓸 수 있다.

```ts
import { … } from '@centurio1987/bbangto-ui-hooks';
```

외부 클릭·미디어 쿼리·리사이즈 옵저버·스토리지·스크롤·네트워크 상태처럼 **동작만** 담당하는 훅들이다.
마크업과 스타일은 호출자가 정한다. 훅마다 단위 테스트가 짝으로 붙어 있다.

전체 저장소: [github.com/centurio1987/bbangto-ui](https://github.com/centurio1987/bbangto-ui)
